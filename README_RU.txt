В архиве все файлы лежат в корне, без дополнительных папок. Загрузите ВСЕ файлы из ZIP в корень репозитория GitHub Pages. Откройте index.html через опубликованный сайт. Нажатия на разделы главной картинки открывают отдельные страницы; на каждой есть кнопки «На главную» и «Назад». Значения демонстрационные, сохраняются только в браузере. Связь с ОВЕН ПР200 не реализована.
